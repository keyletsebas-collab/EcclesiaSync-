# Reglas del Proyecto (LuminaSync / Churchmanager)

- **Compilación en Android:** De ahora en adelante, compila únicamente para Android (APK/AOT) cuando se realicen cambios, a menos que el usuario indique lo contrario de forma explícita. Evita la compilación redundante de Linux u otras plataformas secundarias de escritorio durante las fases de desarrollo estándar.
